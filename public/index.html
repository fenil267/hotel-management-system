Database & Schema / DDL · Triggers · Views · ACID Guarantees
Normalized 3NF Schema
▸ Rooms — room_id PK, room_number UNIQUE, price_per_night, max_occupancy, status
▸ Guests — guest_id PK, email UNIQUE, id_proof_number UNIQUE, phone
▸ Bookings — booking_id PK, guest_id FK, room_id FK, dates, status
▸ Payments — payment_id PK, booking_id FK, amount_paid, method
EngineInnoDB (ACID)
Charsetutf8mb4 / utf8mb4_unicode_ci
Normal Form3NF — no transitive deps
Referential integrityON DELETE CASCADE (Bookings)
SQL Triggers (Auto-State Machine)
⚡ AFTER INSERT — Sets room → Occupied for walk-in or same-day stay
⚡ AFTER UPDATE (Check-In) — Sets room → Occupied
⚡ AFTER UPDATE (Check-Out) — Sets room → Cleaning
⚡ AFTER UPDATE (Cancel) — Sets room → Available
⚡ AFTER DELETE — Releases occupied room → Available
ACID & Concurrency Controls
✓ SELECT … FOR UPDATE row-level locks prevent double-booking
✓ Atomic transactions via beginTransaction() + rollback on failure
✓ Strict interval overlap: (ci < out AND co > in)
✓ CHECK constraints: price > 0, occupancy > 0, checkout > checkin
✓ FK violation protection — cannot delete room with active bookings
View Definition — Booking_Details_View
Denormalized read view used for the reservations ledger and guest history queries
CREATE OR REPLACE VIEW Booking_Details_View AS
SELECT
    b.booking_id,
    b.check_in_date,
    b.check_out_date,
    DATEDIFF(b.check_out_date, b.check_in_date) AS total_nights,
    b.num_guests,
    b.total_amount,
    b.booking_status,
    b.booking_date,
    g.guest_id,
    g.full_name       AS guest_name,
    g.email           AS guest_email,
    g.phone           AS guest_phone,
    g.id_proof_number,
    r.room_id,
    r.room_number,
    r.room_type,
    r.max_occupancy,
    r.price_per_night,
    r.status          AS current_room_status,
    p.payment_id,
    p.amount_paid,
    p.payment_method,
    p.payment_date
FROM   Bookings b
       INNER JOIN Guests  g ON b.guest_id = g.guest_id
       INNER JOIN Rooms   r ON b.room_id  = r.room_id
       LEFT  JOIN Payments p ON b.booking_id = p.booking_id;
